# Nestio オフライン版

タスク管理アプリ Nestio の、**インストール不要・外部と一切通信しない** Windows 用ポータブル版の配布場所です。

## ダウンロード

[Releases](../../releases) から最新の `Nestio-offline-vX.Y.Z-windows-x64.zip` をダウンロードしてください。

## 使い方

1. zip を展開し、`Nestio` フォルダを好きな場所に置く
2. `Nestio.exe` を開く

詳しくは zip の中の `README.md`、コマンド(nestio-cli)は `CLI.md` を見てください。

## アップデート

Nestio を終了してから、新しい zip の中身を **`data` フォルダ以外** 上書きしてください。データは `data` フォルダにあります。

## 動作環境

- Windows 10 / 11(64bit)
- Microsoft Edge WebView2 ランタイム(Windows 10/11 には通常入っています)
